# Variant Design 网站设计系统

本文是 `website/` 的设计规范，写给改网站的人和 Agent。数值以代码为准：变量定义在 `website/src/site-system.css`，首页在 `home.css`，内容页在 `content-pages.css`，灵感参考页在 `inspiration.css`。代码和本文不一致时，先改代码或本文中错的那一方，不要各写各的。

最后核对：2026-11-01，分支 `codex/inspiration-gallery`（灵感页改为图先行浏览结构，结构参考了 recent.design/websites 的公开页面）。

## 1. 定位和语气

网站是一个**设计导航站**：收录外部参考、实测过的设计技能和真实的 A/B/C 案例。Variant Design 技能是其中一个精选条目，不是整个网站。首页的主张是"设计导航，只收核对过的"。

视觉上像一本认真排印的目录：纸色底、墨色字、一种深绿、衬线标题、细线分隔。可信比热闹重要。每个条目都要能回答三个问题：来源是谁、什么时候核对的、还有什么不知道。

## 2. 颜色

只有浅色主题，`html` 声明 `color-scheme: light`。

|---|---|---|---|
| `--site-paper` | `#f7f7f2` | 页面底色 | — |
| `--site-surface` | `#efefe8` | 次级底：切换器底槽、代码块、图片占位 | — |
| `--site-card` | `#fdfdf9` | 浮在纸面上的卡片：首页展示卡、切换器选中块、筛选栏控件 | — |
| `--site-ink` | `#232622` | 正文和标题 | 纸面上 14.2:1 |
| `--site-muted` | `#62665f` | 次要文字：说明、计数、页脚 | 纸面上 5.45:1，surface 上 5.07:1 |
| （正文深灰） | `#41463d` | 首页长段落 | 纸面上 9.0:1 |
| `--site-line` | `#d7d9d1` | 分隔线、卡片边框 | 只做装饰线，不承担信息 |
| `--site-accent` | `#e1e9d8` | 浅绿底，少量强调 | — |
| `--site-brand` | `#2e4325` | 主按钮底、链接、焦点环、输入光标、表单控件、选中的筛选胶囊 | 纸面上 10.0:1；白字在其上 10.8:1 |
| `--site-wash` | `#d6e2c8` | `::selection` 底色（配 `--site-ink`），分析卡底色之一 | 品牌绿在其上 8.0:1 |
| `--site-scrim` | `rgba(35,38,34,.4)` | 弹层背后的压暗层，配 6px 模糊 | 只做遮罩 |

规则：

- 文字至少 4.5:1。新写的颜色只能从上表取，不要再加新的灰绿色。
- 品牌绿只用于"可以点的东西"和焦点状态，不用来装饰。
- 不用渐变，不用纯黑和纯白做大面积底色（主按钮上的白字除外）。
- 色彩留给内容：浏览页的界面本身只用纸色、墨色和品牌绿，缩略图之间的区别靠分析卡的底色（`--site-card`、`--site-surface`、`--site-accent`、`--site-wash`、`--site-paper`）和结构草图。
- 例外：灵感页"动效"分类里的参考演示（如 `PaperWidgets.tsx`）是在复现外部作品的效果，可以用自己的配色、渐变和深色底，演示内部的小组件文字也可以小于 12px（按原作品的比例缩小），但变量和样式只能写在演示根元素（`.paper-widgets`）内部，不外泄到站点；演示外的说明文字仍遵守第 3 节。图标照样用 SVG，不用字形符号。

## 4. 布局和间距

- **容器**：`.site-shell` 宽度为 `min(1280px, 100% - 96px)`。800px 以下改为 `100% - 40px`，480px 以下改为 `100% - 32px`。
- **断点**：1000px（首页首屏改单列，主张在前）、800px（导航变紧凑）、650px（导航可横向滚动）、480px（页脚竖排）。
- **区块**：首页各区块 `padding-block: 72px`，之间用一条 `--site-line` 顶线分隔。首屏 `padding-block: 64px 80px`。
- **间距**：区块内用 `gap`，不要逐个元素加 margin。常用值：
  - 按钮组 12px；
  - 链接组 20px；
  - 卡片内 12–14px；
  - 两栏之间 64–72px。
- **防溢出**：网格子元素要加 `min-width: 0`，长文本才会换行。每个页面在 320 / 390 / 1440 宽度下都不能横向滚动。`tests/landing.spec.mjs` 只检查了一部分页面，`/pricing`、`/lab`、`/d/<案例>`、`/showcase` 等还没有覆盖，改这些页面时要自己截图检查。
- **行宽**：正文不超过 68ch，引导段落不超过 46ch。
- **间距变量**：`--space-1` 到 `--space-7` 依次是 4 / 8 / 12 / 16 / 24 / 32 / 48px。新代码用变量，不再写零散的像素值。

### 浏览页布局（灵感参考）

条目多、需要扫视的页面用这套结构，不用首屏大标题：

1. **标题行**：衬线标题（`clamp(30px, 3vw, 40px)`）和一句灰色说明放在同一行，右端放"投稿与授权规则"链接。下面一行是各分类的数量（正文字体 13px，从数据算出），再下面是可展开的版权说明（`<details>`），收起时只占一行。
2. **筛选栏**：`position: sticky; top: 0`，上下各一条细线。左边是可横向滚动的分类胶囊，右边依次是专题下拉、搜索框（⌘K / Ctrl+K 聚焦，聚焦或有内容时从 110px 展开到 200px）、排序下拉。650px 以下胶囊独占一行。
3. **网格**：`repeat(auto-fill, minmax(260px, 1fr))`，间距 12px，卡片 16:10。1440px 下 4 列，1920px 下仍受 `.site-shell` 限宽。
4. **分页**：先显示 24 个，滚动接近底部时自动加载下一批（IntersectionObserver），同时保留"加载更多（还有 N 个）"按钮作兜底。
5. **详情**：从网格点开是弹层（地址变成 `/inspiration/<id>`），直接访问这个地址是完整页面，有自己的标题和描述（构建时预渲染）。左栏是笔记，右栏是大图和"访问原站"。1023px 以下改单列：工具条 → 大图 → 笔记，弹层全屏。

## 5. 圆角、边框、阴影

| 值 | 用于 |
|---|---|
| `--radius-pill` 999px | 胶囊：首页切换器和选中块、筛选胶囊、搜索框、下拉、卡片上的圆形按钮、详情工具条 |
| `--radius-panel` 12px | 首页展示卡、详情弹层、详情大图、参考包和指令面板 |
| `--radius-card` 8px | 缩略图卡片、来源链接卡、参考包内的分组 |
| `--radius-control` 6px | 按钮、代码块、图片、价格卡、文本框 |
| 4–5px | 历史值，见第 10 节第 5 条，新组件不要用 |

规则：

- 物体之间优先用 1px 细线分隔，少用卡片。
- 卡片只用边框，不同时用边框加阴影。
- 全站唯一的阴影是切换器选中块的 `0 1px 2px rgba(35,38,34,.14)`。弹层也不加阴影，靠 `--site-scrim` 压暗和细边框区分层级。

## 6. 动效

- **切换**：所有状态切换都调用 `website/src/view-transition.ts` 的 `transition()`。浏览器不支持 View Transitions 或用户开了"减少动态效果"时，直接切换。
- **用在哪里**：只给用户主动操作的切换加动画，包括切换器、筛选、中英切换和字体开关。不加滚动入场、数字滚动或循环动画。
- **时长和曲线**：元素移动 0.34s，整页淡入淡出 0.18s，曲线 `cubic-bezier(.22,1,.36,1)`（`--ease-out`）。
- **短交互**：悬停时的显隐和边框颜色变化用 `--dur-fast`（140ms）；弹层打开用 `--dur-base`（200ms），内容从 `scale(.98)` 淡入，背后的压暗层同步淡入；搜索框展开也用 200ms。关闭不做动画。
- **悬停**：只在 `(hover: hover)` 且不减少动效时生效。悬停只改线的粗细或颜色，或让已经在原位的控件显现，不位移、不缩放。触屏设备（`hover: none`）上，悬停才出现的控件一直显示。
- **元素命名**：需要跟着移动的元素设 `view-transition-name`，名字必须唯一，参考卡片用 `ref-<id>`。

## 8. 文案

- **双语**：所有文案都提供中英两份，数据里按 `[中文, 英文]` 的顺序写。大段文案放在数据结构里，不直接写在 JSX 中。
- **写法**：直接、具体，句首大写、其余小写（sentence case）。不用全大写标签，不用表情符号，首页的链接和按钮里不放 `→ ↗ ↓` 这类箭头。
- **数字**：从数据算出来，比如"26 个参考"由 `inspirationItems.length` 得出，不要手写。
- **诚实**：不知道的事直接写出来，比如"设计者：未知""登录后操作未实测"。没测过的东西不写成"支持"。
- **第三方内容**：只放链接和我们自己写的研究笔记，不复制对方的文案、商标和截图。
- **原站截图**：只有条目记录了授权时才显示。数据里写 `media`：本地文件路径（`/inspiration-media/` 下）、尺寸、中英替代文字，以及 `permission`（谁授权、日期、条件）；`website/scripts/inspiration-data.test.mjs` 会检查这些字段和文件。不用对方的 og:image，也不热链对方的图片。出现第一张授权截图时，同步改灵感页的版权说明和 `/submit`。

## 9. 不要做

这些做法会让网站像 AI 批量生成的页面。依据是 Impeccable 的 craft floor 和检测器，可以用 `npx -y impeccable@4.8.0 detect --json <url>` 检查：

- 眉标或小标题标签，比如 `REFERENCE LIBRARY / 001`；
- 给不是步骤的内容编号，比如 `01 / 02 / 03`；
- 一排外观完全相同的卡片网格当作主视觉。图片网格可以用，但每张图要能一眼看出区别（内容不同，或分析卡的草图和底色不同）；
- 卡片同时用边框和阴影；
- 用字形符号当图标；
- 用等宽字体做装饰；
- 渐变和发光效果；
- 过度使用的字体：Inter、Roboto、Arial、Fraunces、Instrument Serif、Instrument Sans、Geist、Space Grotesk 等。

## 10. 已知偏差

下面这些是现有代码里不符合上述规范的地方，改到相关页面时顺手修掉：

1. **对比度不足**（纸面或卡片底上）：

   | 颜色 | 位置 | 对比度 |
   |---|---|---|
   | `#757d6b` | 页脚 | 3.99:1 |
   | `#83867e` | 字标 "design" 部分 | 3.44:1 |
   | `#7a846f` | 眉标 | 3.65:1 |

   改成 `--site-muted` 即可。
2. **灰绿色太多**：`content-pages.css` 和 `library.css` 里有十几个一次性的灰绿色，比如 `#65745a`、`#5d6e4f`、`#ced6c4`，应该收进第 2 节的颜色。`inspiration.css` 已经全部改用变量。
3. **焦点环两种颜色**：导航、页脚和部分内容页用的是蓝色 `#325ecb`，应统一成品牌绿。灵感页的页面内容已经改成品牌绿，导航和页脚还是蓝色。
4. **非首页还有眉标**：`/skills`、`/docs`、`/pricing`、`/lab`、`/about` 页面顶部仍有等宽眉标，`/docs` 的章节编号 `00.` 到 `05.` 也是同一类问题。
5. **圆角不统一**：还有 4px 和 5px 的圆角（筛选按钮、参考卡片、输入框），应向 6px 靠拢。

## 11. 修改流程

1. 先改 `site-system.css` 里的变量，不要在组件里写新的颜色值。
2. 跑测试：

   ```sh
   npm test --prefix website && npm run build --prefix website
   cd tests && PLAYWRIGHT_CHANNEL=chrome npx playwright test -c landing.config.mjs
   ```

3. 视觉改动要在 320 / 390 / 1440 三个宽度、中英两种语言下截图检查，再用 Impeccable 检测器检查一遍首页。
4. 改了本文描述的数值，要在同一个 PR 里同步更新本文。
