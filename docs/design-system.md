# Variant Design 网站设计系统

本文是 `website/` 的设计规范，写给改网站的人和 Agent。数值以代码为准：变量定义在 `website/src/site-system.css`，首页就是灵感作品流，在 `inspiration.css`；内容页在 `content-pages.css`；`home.css` 只剩赞助页用的主次按钮。代码和本文不一致时，先改代码或本文中错的那一方，不要各写各的。

最后核对：2026-11-11，分支 `codex/gehirn-phase3`（内页标题和页脚行动区统一，见 12.2）；同日较早：`codex/gehirn-phase2`（氛围层的外壳扩展到指南、案例、文档、技能、价格、赞助、投稿、关于、更新记录和实验室页，见第 12 节；横向画廊仍只在灵感页）。上一次：2026-11-10，分支 `codex/gehirn-feel-redesign`。上一次：2026-11-04，分支 `codex/content-style-budget`（文档和赞助页字号收敛；统一作品流见 RFC-008）。

## 1. 定位和语气

网站是一个**设计灵感站**，定位语是"互联网上最好的设计灵感"（RFC-008）。首页是图先行的作品流，每条附出处、核对日期和我们写的笔记。A/B/C 案例在 `/cases`。Variant Design 技能是"资源"里的一项，它的文档、价格和关于页在页脚的技能分组里。

视觉上像一本认真排印的目录：纸色底、墨色字、一种深绿、衬线标题、细线分隔。可信比热闹重要。每个条目都要能回答三个问题：来源是谁、什么时候核对的、还有什么不知道。

只有浅色主题，`html` 声明 `color-scheme: light`。

| `--site-card` | `#fdfdf9` | 浮在纸面上的卡片：首页展示卡、切换器选中块、筛选栏控件 | — |
| `--site-ink` | `#232622` | 正文和标题 | 纸面上 14.2:1 |

| `--site-accent` | `#e1e9d8` | 浅绿底，少量强调 | — |
| `--site-brand` | `#2e4325` | 主按钮底、链接、焦点环、输入光标、表单控件、选中的筛选胶囊 | 纸面上 10.0:1；白字在其上 10.8:1 |
| `--site-wash` | `#d6e2c8` | `::selection` 底色（配 `--site-ink`），分析卡底色之一 | 品牌绿在其上 8.0:1 |
| `--site-scrim` | `rgba(35,38,34,.4)` | 弹层背后的压暗层，配 6px 模糊 | 只做遮罩 |

规则：

- 文字至少 4.5:1。新写的颜色只能从上表取，不要再加新的灰绿色。双色标题（`/about`、`/pricing`、实验室）的第二行用 `--site-muted`，不要用更浅的灰。
- 品牌绿只用于"可以点的东西"和焦点状态，不用来装饰。
- 不用渐变，不用纯黑和纯白做大面积底色（主按钮上的白字除外）。
- 色彩留给内容：浏览页的界面本身只用纸色、墨色和品牌绿，缩略图之间的区别靠分析卡的底色（`--site-card`、`--site-surface`、`--site-accent`、`--site-wash`、`--site-paper`）和结构草图。
- **例外**：所有页面（`.content-page`、`.pricing-page`、`.paper-home`）使用云天背景和半透明面板，这是第 12 节单独规定的氛围层，颜色和渐变只用在页面背景与面板上，不用在按钮、卡片或文字上。按钮、卡片和文字仍遵守上面的规则。

## 3. 字体

| 角色 | 变量 | 字体栈 | 来源 |
|---|---|---|---|
| 标题 | `--font-display` | Libre Caslon Display → PingFang SC → Hiragino Sans GB → Microsoft YaHei | Caslon 来自 `@fontsource/libre-caslon-display`；中文用访问者设备的系统字体 |
| 正文 | `--font-serif`（名字是历史遗留，实际是无衬线） | Hanken Grotesk → PingFang SC → Microsoft YaHei | `@fontsource-variable/hanken-grotesk` |
| 代码 | `--font-mono` | IBM Plex Mono → SFMono-Regular → Consolas | `@fontsource/ibm-plex-mono` |

拉丁字体（Caslon、Hanken Grotesk、IBM Plex Mono）都打包在网站里自己提供，不从 Google Fonts 加载，因为国内访问不到。**中文不打包字体**，一律用系统字体：苹果设备上是苹方（PingFang SC），其他设备退到冬青黑体（Hiragino Sans GB）或微软雅黑。所以中文标题是无衬线，英文标题是衬线；在 Windows 和 Android 上中文的样子会和苹果设备不同。

2026-11-12 起不再使用霞鹜新致宋，页脚的 IPA 授权说明和「改用 IPA 原版字体」开关一并删除。`/fonts/LICENSES.txt` 仍保留，列出打包字体的 OFL 授权。

| 次要说明、按钮、导航 | `.home-tasks li p`、`.home-actions a`、`.site-language` | 14px | 1.7 |

规则：

- 标题用 `--font-display`，字重 500，`font-synthesis: none`，字距 -0.01em。衬线标题不要再收紧字距，也绝不能小于 -0.04em。
- 衬线只用于标题，正文、按钮和表单一律用无衬线。
- 小于 12px 的字不要再加。
- **数量预算**：一个页面在 1440 宽度下最多用 7 个字号、3 种字体（标题、正文、等宽）、5 种文字颜色、3 种圆角（胶囊算一种）。用 `scripts/style-budget.mjs` 量，见第 11 节。相差 1–2px 的字号要合并，不要并存。
- 等宽字体只用于代码、命令和日期。不要用等宽字体做眉标、分类标签或装饰。

## 4. 布局和间距

- **容器**：`.site-shell` 宽度为 `min(1280px, 100% - 96px)`。800px 以下改为 `100% - 40px`，480px 以下改为 `100% - 32px`。
- **断点**：1000px（首页首屏改单列，主张在前）、800px（导航变紧凑）、650px（导航链接换到第二行，各占满一行；极窄时仍可横向滚动）、480px（页脚竖排）。
- **手机上的可点和可读**（650px 以下）：导航、页脚、目录和单独成行的链接，点击区域至少 44px 高（导航链接字号随屏宽 12–14px，6 个链接在 320px 宽仍排一行）；输入框、下拉和文本框用 16px 字，避免 iOS 聚焦时放大页面；正文和标签不小于 12px（示例产品界面里的缩略内容除外）。`tests/landing.spec.mjs` 的“on phones, links and fields are big enough to tap and read”检查这三条。
- **区块**：说明页（如 `/sponsor`）各区块 `padding-block: 72px`，之间用一条 `--site-line` 顶线分隔。首屏 `padding-block: 64px 80px`。
- **间距**：区块内用 `gap`，不要逐个元素加 margin。常用值：
  - 按钮组 12px；
  - 链接组 20px；
  - 卡片内 12–14px；
  - 两栏之间 64–72px。
- **防溢出**：网格子元素要加 `min-width: 0`，长文本才会换行。每个页面在 320 / 390 / 1440 宽度下都不能横向滚动。`tests/landing.spec.mjs` 只检查了一部分页面，`/pricing`、`/lab`、`/d/<案例>`、`/showcase` 等还没有覆盖，改这些页面时要自己截图检查。
- **行宽**：正文不超过 68ch，引导段落不超过 46ch。
- **技能条目**（`/skills`）：桌面两栏，左边名称、说明和实测方式，右边安装命令和公开记录；900px 以下合成一栏。安装命令自动换行，不横向滚动。
- **左边缘**：正文栏（`.content-reading`）和页面标题共用 `.site-shell` 的左边缘，只限制子元素宽度（760px），不把整栏居中。
- **间距变量**：`--space-1` 到 `--space-7` 依次是 4 / 8 / 12 / 16 / 24 / 32 / 48px。新代码用变量，不再写零散的像素值。

### 浏览页布局（灵感参考）

条目多、需要扫视的页面用这套结构，不用首屏大标题：

> 灵感页（`.inspiration-page`）已改为横向画廊和氛围层，第 3 步的网格规则对它不再适用，以第 12 节为准；其余步骤（标题行、筛选栏、分页、详情）仍然有效。

1. **标题行**：首页的定位语是衬线标题（`clamp(28px, 3.4vw, 46px)`；中文在 1440 和 390 宽度下各占一行，英文在 390 下折成两行），下面一行是灰色说明（16px，最多 56ch），右端放"投稿与授权规则"链接。下面一行是各分类的数量（正文字体 14px，从数据算出），再下面是可展开的版权说明（`<details>`），收起时只占一行。
2. **筛选栏**：`position: sticky; top: 0`，上下各一条细线。左边是可横向滚动的分类胶囊，右边依次是专题下拉、搜索框（⌘K / Ctrl+K 聚焦，聚焦或有内容时从 110px 展开到 200px）、排序下拉。650px 以下胶囊独占一行。
3. **网格**：网站与 X 视频共用 `repeat(auto-fill, minmax(250px, 1fr))`，行距 24px、列距 16px，媒体 16:10，完整展示图片或视频，不裁去内容。1440px 下 4 列，首屏露出两行；650px 以下 2 列、360px 以下 1 列。缩略图不加边框、底色或圆角；没有预览时保留原创分析卡。分析卡标题 20px。默认按 `addedAt` 降序（历史值取首次收录该条目的 Git 提交时间）；核对日期单独保留。分类、专题、搜索和排序进入 URL，原编辑顺序仍可选。
4. **分页**：先显示 30 个（5 列的整数倍），滚动接近底部时自动加载下一批（IntersectionObserver），同时保留"加载更多（还有 N 个）"按钮作兜底。
5. **详情**：从网格点开是弹层（地址变成 `/inspiration/<id>`），直接访问这个地址是完整页面，有自己的标题和描述（构建时预渲染）。左栏是笔记，右栏是大图和"访问原站"。1023px 以下改单列：工具条 → 大图 → 笔记，弹层全屏。打开、切换和关闭通过唯一的 `ref-<id>` 做共享元素过渡；弹层中的背景卡片不占同名。详情支持左右键、Esc，关闭后恢复原来的滚动位置和触发链接的焦点，浏览器前进/后退仍可使用。减少动效或没有 View Transitions API 时立即切换。

灵感页在 `.inspiration-page` 内把 `--radius-card`、`--radius-panel` 设为 16px（面板、卡片、弹层），缩略图和结构草图线条用 3px，头像和胶囊用 full，共三种，不再用 6px。下表是其他页面仍沿用的全站基础值。首页末尾标题统一 28px，手机导航固定 12px，防止连续字号增加计数。

| `--radius-panel` 12px | 首页展示卡、详情弹层、详情大图、参考包和指令面板 |
| `--radius-card` 8px | 缩略图卡片、来源链接卡、参考包内的分组 |
| `--radius-control` 6px | 按钮、代码块、图片、价格卡、文本框 |

规则：

- 物体之间优先用 1px 细线分隔，少用卡片。
- 卡片只用边框，不同时用边框加阴影。

## 6. 动效

- **切换**：所有状态切换都调用 `website/src/view-transition.ts` 的 `transition()`。浏览器不支持 View Transitions 或用户开了"减少动态效果"时，直接切换。
- **用在哪里**：只给用户主动操作的切换加动画，包括切换器、筛选、中英切换和字体开关。不加滚动入场、数字滚动或循环动画。
- **时长和曲线**：令牌定义在 `site-system.css` 的 `:root`（页面切换的伪元素也要读到），不要手写时长和曲线：`--ease-out`（`cubic-bezier(.22,1,.36,1)`）、`--dur-press` 160ms、`--dur-fast` 140ms、`--dur-base` 200ms、`--dur-slow` 340ms。元素移动用 `--dur-slow`，整页淡入淡出用 `--dur-base`。界面动画不超过 300ms，只有页面级的元素移动例外。
- **短交互**：悬停时的显隐和边框颜色变化用 `--dur-fast`（140ms）；筛选项只变颜色，不上移；收藏按钮用颜色过渡加按下时 `scale(.94)`（`--dur-press`），不用 `@keyframes`，因为连点时关键帧会从头重播而过渡可以中途反转；弹层打开用 `--dur-base`（200ms），内容从 `scale(.98)` 淡入，背后的压暗层同步淡入。关闭不做动画。搜索框宽度固定为 160px，不做展开动画：动画 `width` 会逐帧触发布局，并挤动同一栏里的其他控件。生成的参考指令面板用 200ms 的 `translateY(8px)` 加淡入出现（减少动效时只淡入）。
- **悬停**：只在 `(hover: hover)` 且不减少动效时生效。通常只改线的粗细或颜色，或让已经在原位的控件显现；灵感卡片缩略图可以微缩放到 `1.025`，用 `--dur-base`（200ms），不移动卡片布局；这是全站最常碰的元素，不要比 300ms 更慢。案例卡片和首页按钮箭头的悬停位移同样放在 `(hover: hover) and (pointer: fine)` 里，触屏点一下不会误触发。触屏设备（`hover: none`）上，悬停才出现的控件一直显示。
- **页面之间**：整页导航（例如切换分类 tab）用跨文档 View Transitions 做淡入淡出（`site-system.css` 的 `@view-transition`，减少动效时不启用；不支持的浏览器直接跳转）。监听写在 `website/index.html` 的内联脚本里，因为 `pagereveal` 早于延迟加载的模块。过渡期间 `<html>` 带 `vt-cross` 类，临时去掉卡片的 `ref-<id>` 命名，否则两页都有的同一条参考会在屏幕上飞来飞去；过渡结束后命名恢复，同页的卡片到详情过渡不受影响。
- **减少动效**：去掉位移和缩放，保留透明度和颜色的反馈，弹层仍然淡入。灵感页在减少动效时只允许 `opacity`、`color`、`background-color`、`border-color` 做过渡。
- **不动画布局属性**：`width`、`height`、`padding`、`margin`、`top`、`left` 不做过渡，每帧触发布局。`/lab` 的预览框在手机和桌面布局之间直接切换。
- **元素命名**：需要跟着移动的元素设 `view-transition-name`，名字必须唯一，参考卡片用 `ref-<id>`。

## 8. 文案

- **双语**：所有文案都提供中英两份。新文案按语言取值，写成 `{ zh: '…', en: '…' }`，用 `t()` 读取（RFC-005）；还没迁移的数据仍是 `[中文, 英文]`，改到哪个文件就换成新写法。大段文案放在数据结构里，不直接写在 JSX 中。
- **写法**：直接、具体，句首大写、其余小写（sentence case）。不用全大写标签，不用表情符号，首页的链接和按钮里不放 `→ ↗ ↓` 这类箭头。
- **数字**：从数据算出来，比如"26 个参考"由 `inspirationItems.length` 得出，不要手写。
- **诚实**：不知道的事直接写出来，比如"设计者：未知""登录后操作未实测"。没测过的东西不写成"支持"。
- **第三方内容**：只放链接和我们自己写的研究笔记，不复制对方的文案、商标和截图。
- **X 帖子（Best practice）**：Ego Lite 每周在已登录的 X 搜索最近一周、至少 100 个赞的设计视频，链接进入 `website/content/x-post-inbox.json`；这只是待筛选候选，不会自动发布。用 `node website/scripts/x-post.mjs <帖子链接> --tag <标签>` 通过 X 官方 oEmbed 生成草稿，只记作者、日期、语言和正文；看过原帖后再手写「研究什么」「用在哪里」，草稿里的 TODO 不能留下（单元测试会查）。草稿记录 `addedAt`（首次收录时间，ISO 时间戳），后续复核只改 `checkedAt`，不要重排历史收录时间。X 帖子进入「全部」作品流，也可在 Best practice 分类单独筛选。卡片就是帖子视频本身：静音、循环，只在可见时播放，减少动效时移除视频源，只保留封面；偏好运行中变化时立即停播、移除源，改回允许动效后按可见状态恢复；切换后台页也暂停；作者头像随署名显示，收藏和来源按钮在悬停、聚焦或触屏时显示。视频地址、封面和头像由 `node website/scripts/x-media.mjs` 从 X 嵌入组件背后的接口（`cdn.syndication.twimg.com`，未公开文档）读出，写进 `website/src/x-media.json`，不下载、不转存，页面直接从 video.twimg.com 播放。video.twimg.com 拒绝带其他网站来源的请求，所以灵感页在播放前把文档的 referrer 策略设为 `no-referrer`。这条路径是维护者 2026-11-01 明确选择的例外，等于绕过 X 的防盗链，X 随时可能堵住；视频失败时卡片退回封面图，封面也加载不了（例如国内网络访问不到 pbs.twimg.com）时退回该条目的分析卡，头像加载失败则隐藏，不露出破图。详情页仍用 X 官方嵌入组件，说明里写明 X 可能记录这次访问。嵌入加载完成前先显示存下来的正文；连不上 x.com 时保留正文和「在 X 上打开」。不下载、不托管帖子里的媒体，也不另写演示复刻帖子里的效果。
- **经其他策展站发现的作品**：条目写 `via`（该站这件作品的页面地址），详情的出处后显示「经 某站 发现」并链接过去。只按我们自己看过、写过笔记的条目加入，不整批搬运别人的精选列表。
- **网站缩略图**：直接用链接自己的内容，不自己再画或再写一遍对方的页面。`node website/scripts/link-preview.mjs` 对每个链接请求一次，读出对方为分享链接公开的 og:/twitter: 预览（图片、标题、描述），写进 `website/src/link-previews.json`；页面只存图片地址，仓库里不下载、不转存、不裁切；显示时经 Vercel 图片服务（`/_vercel/image`，`vercel.json` 的 `images`）按显示尺寸缩小成 WebP 并缓存，卡片 640px、详情 1280px（2026-11-01 维护者为加载速度选定）。缩小失败时直接从原站加载（`referrerPolicy=no-referrer`）。`link-preview.mjs` 会把新图片的域名同步进 `remotePatterns`。没有预览的（2026-11-01：Lovable、Aesop 拒绝脚本访问，Nothing 没有 og:image）和加载失败的显示分析卡。不嵌入整站：多数站点用 X-Frame-Options 或 frame-ancestors 禁止被嵌入。不自己截图或录屏。

## 9. 不要做

这些做法会让网站像 AI 批量生成的页面。依据是 Impeccable 的 craft floor 和检测器，可以用 `npx -y impeccable@4.8.0 detect --json <url>` 检查：

- 眉标或小标题标签，比如 `REFERENCE LIBRARY / 001`；
- 给不是步骤的内容编号，比如 `01 / 02 / 03`；
- 一排外观完全相同的卡片网格当作主视觉。图片网格可以用，但每张图要能一眼看出区别（内容不同，或分析卡的草图和底色不同）；
- 卡片同时用边框和阴影；
- 用字形符号当图标；
- 用等宽字体做装饰；
- 渐变和发光效果；
- 过度使用的字体：Inter、Roboto、Arial、Fraunces、Instrument Serif、Instrument Sans、Geist、Space Grotesk 等。

## 10. 已知偏差

下面这些是现有代码里不符合上述规范的地方，改到相关页面时顺手修掉：

1. **对比度不足**：页脚、字标和内容页、价格页、关于页的说明文字已在 2026-11-01 改成 `--site-muted`，Impeccable 检测器在首页、`/docs`、`/pricing`、`/skills` 上为 0 项。剩下的是关于页里缩小的产品界面示意（`CapabilityShowcase`），里面的界面文字按比例缩到 6–10px，检测器仍会报。
2. **灰绿色太多**：`content-pages.css` 和 `library.css` 里有十几个一次性的灰绿色，比如 `#65745a`、`#5d6e4f`、`#ced6c4`，应该收进第 2 节的颜色。`inspiration.css` 已经全部改用变量；文档页正文、链接、命令框和控件已统一到 ink / muted / brand / surface / line。
3. **焦点环（已统一，2026-11-08）**：公开页面的焦点环都是 `var(--site-brand)` 的 2px 实线，对背景的对比度在 8.66 到 10.04 之间（WCAG 2.2 的线是 3:1）。以前导航、页脚、案例页、技能页、指南页、更新记录、实验室、关于页是蓝色 `#325ecb`。`tests/landing.spec.mjs` 用 `tests/focus-probe.mjs` 在 16 个页面上逐个 Tab，检查颜色、宽度和对比度。**这只检查焦点环，不是 WCAG 合规结论。** 两个有意的例外：语言提示条是深色底，用浅色环（对比度 13.44）；`/about` 的实时预览 iframe 本身是可进入的 Tab 停靠点，它里面的环由被预览的页面决定。
4. **非首页还有眉标**：`/skills`、`/docs`、`/pricing`、`/lab`、`/about` 页面顶部仍有等宽眉标，`/docs` 的章节编号 `00.` 到 `05.` 也是同一类问题。
5. **圆角不统一**：首页和页头的 3–5px 圆角已改为 6px（2026-11-02）。`library.css` 里案例详情页的标签、输入框和按钮还有 3–5px，应向 6px 靠拢。
6. **氛围层的外壳已覆盖全站，内页内容未重做**：外壳（云天背景、面板、页头、页脚、圆角变量）在 `website/src/atmosphere.css`，最后一个加载。各页内部的版式（指南列表、文档卡片、技能详情、价格卡片）只改了底色和圆角，字号层级和间距还是旧的；横向画廊只用于灵感页。

## 11. 修改流程

1. 先改 `site-system.css` 里的变量，不要在组件里写新的颜色值。
2. 跑测试：

   ```sh
   npm test --prefix website && npm run build --prefix website
   cd tests && PLAYWRIGHT_CHANNEL=chrome npx playwright test -c landing.config.mjs
   ```

3. 视觉改动要在 320 / 390 / 1440 三个宽度、中英两种语言下截图检查，再用 Impeccable 检测器检查一遍首页。改了字号、颜色或圆角，用 `scripts/style-budget.mjs` 在 1440 宽度下量改动前后的数量（用法见 `references/workflow/adjective-translation.md`）。
4. 改了本文描述的数值，要在同一个 PR 里同步更新本文。


## 12. 氛围层（灵感页）

2026-11-10 起，灵感页放在一张云天背景上，内容在一块半透明的面板里，作品排成一条横向画廊。参考的是 gehirn.md 的整体气质：安静、留白大、界面几乎不抢作品。背景图、标题字体和版式都是我们自己做的，没有使用对方的素材。

### 结构

- **背景**：`html:has(.inspiration-page)` 设置 `/sky.jpg`（1600px 宽，约 76KB，`cover` 固定），`body` 在这个页面透明。图片由 `website/scripts/sky-source.svg` 预渲染而来：用无头 Chrome 在 1920×1200 下截图，再缩到 1600 宽、JPEG 质量 52。不要把 SVG 滤镜直接当背景，它在浏览器里实时计算，满屏固定背景会拖慢滚动。改云的形状时改 SVG 源，重新渲染一张 JPEG。
- **面板**：`.inspiration-page` 本身是面板。宽 `min(1240px, 100% - 64px)`，`rgba(255,255,255,.62)` 加 22px 背景模糊，1px 白色描边，圆角 16px，顶部圆角、底部贴边。不支持 `backdrop-filter` 时退回 `rgba(255,255,255,.88)`。面板内的 `.site-shell` 改为 `width:auto` 加 32px 内边距，手机 16px。
- **面板上边距用 `transform: translateY(28px)`，不用 `margin`**（手机 8px）。预渲染的详情页只是一个裸 `<main>`，React 接管后才换成面板；用外边距会把整个 `body` 推下 28px，记为约 0.02 的布局偏移，`transform` 不计入。
- **页头**：沿用 `SiteHeader`，只改外观：字标用标题字体 20px，当前页用下划线，语言按钮是胶囊，下方一条细线。没有新增深色模式开关或"安装"按钮。
- **页脚**：隐藏绿色的 `.site-footer-cta`（它和页面末尾的 `.content-closing` 重复），保留链接分组和字体授权行。

### 横向画廊

- `.inspiration-grid.insp-feed` 是单行 `grid-auto-flow: column`，卡片宽 300–360px（手机 78vw），`overflow-x: auto`，`scroll-snap-type: x proximity`，并设 `scroll-padding-inline` 与内边距相同，否则吸附会吃掉起点的内边距。
- 卡片是白色底加 1px 细线、16px 圆角、8px 内边距；缩略图 4:3、3px 圆角；署名（头像、名称、来源）固定显示在图下方，不再悬停才出现。
- 加载仍是原来的 IntersectionObserver 加"加载更多"按钮；DOM 结构、键盘导航、弹层和视图过渡没有改动。
- 画廊下方有进度（`01 / 99`）和左右箭头，箭头按 80% 的视口宽度滚动，减少动效时不用平滑滚动。起点处"向左"禁用，滚到底"向右"禁用。这是这一轮唯一新增的交互。

### 预算与取舍

- 沿用同一套预算，1440 宽实测（`scripts/style-budget.mjs` 的 probe，2026-11-10）：7 个字号（12、13、14、16、20、28、68，已用满上限，再加字号要先合并现有的）、2 种字体、2 种字重（400、500）、4 种文字颜色、3 种圆角（full、16px、3px）、2 种阴影。
- **没有使用等宽字体做小标签。** gehirn.md 用等宽大写做眉标，但本站预算是每页两种字体、第 3 节也不允许等宽眉标。这里改用正文字体加 `letter-spacing: .1em`。想要等宽眉标，要先改预算和第 3 节。
- 标题没有用窄身衬线体（如 Instrument Serif），仍是 Caslon（中文走苹方），因为第 9 节把它列为过度使用的字体。
- 文案没有改，页面标题仍是"互联网上最好的设计灵感。"。

### 测试变更

- `tests/inspiration-browsing.spec.mjs`：原来要求桌面端署名悬停才出现、首屏完整显示 8 张卡片（两行）。横向画廊下这两条契约不再成立，改为：署名在所有宽度都可见，桌面首屏完整显示 3 张卡片。视觉预算检查保持不变。
- `tests/landing.spec.mjs`：灵感页的图片请求白名单加入第一方的 `/sky.jpg`。
- 布局偏移：X 嵌入测试（上限 0.02）在改动前后的实测约 0.0013–0.0017（`transform` 方案）；用 `margin` 时为 0.0209，不通过。

### 尚未验证

- 没有在 Safari 和 Firefox 里看过，`backdrop-filter` 和 `scroll-snap` 的表现未知。
- 面板里文字对云背景的对比度没有逐点测量，只做了视觉检查；`--site-muted` 在此页改为 `#4d525a`，比全站的 `#62665f` 更深。不要据此声称符合 WCAG。
- 其他页面尚未应用这一层，见第 10 节第 6 条。

## 投稿表单与授权状态（2026-11-04）

`/submit` 的 `.submission-intake` 分作品/媒体、署名/授权两个 fieldset。桌面两列，650px 以下一列；输入控件至少 44px 高、16px 字。表单不持久化或自动发送。准备后先显示按作品、媒体、署名与权限分段的可读正文，提供复制、下载草稿、打开 GitHub 和显式媒体预览；复制或下载失败保留正文。授权勾选默认关闭。没有 JavaScript 时引导使用 GitHub 模板。

作者授权卡片显示「作者授权」，详情附署名链接、授权记录、范围和撤下入口；视频复用现有可见播放/减少动效行为。媒体失败不从其他来源替换授权内容。撤下地址保留无媒体、noindex 的说明，既有参考包笔记标为不可用并排除于指令。来源、授权范围和状态都不得用装饰性徽章代替具体说明。


## 文档与赞助页的样式预算（2026-11-04）

文档页由 `ContentPages` 标记 `.docs-page`，只在该页收敛正文、目录、命令、控件和结束区字号，不改写其他内容页的规则。正文和命令输入框为 16px，目录、按钮和短命令为 14px；章节与结束区标题统一为桌面 30px、600px 以下 26px，保留 h3 的 20px。命令框保留 Plex Mono、只读和复制功能。页脚统一 14px，控件圆角统一 6px，焦点环用品牌绿。

赞助页引导、条目标题和正文统一 16px，条目标题靠 500 字重区分；保留衬线章节标题、分隔线和主次按钮。没有改动赞助规则、链接或表单行为。

`tests/landing.spec.mjs` 使用真实 Chrome 和共享 probe，对 `/docs`、`/sponsor` 的中英文 × 320/390/1440 检查字号、颜色、圆角和溢出，附原始 JSON 与截图。文档的命令 textarea 会被 probe 计入字体，按本规范已有的三种字体预算检查；其他限制沿用脚本默认值，未改 probe。桌面两页各 6 个字号，390px 各 7 个；文档 4 种文字颜色、赞助 5 种、圆角均 1 种。测量指加载 JavaScript 后的页面；中文无 JS 安装正文仍由原有 `docsBody` 输出，不据此声称它拥有相同布局或计数。记录见 `docs/research/2026-11-04-content-style-budget.md`。

### 12.1 扩展到全站（第二阶段）

- 外壳规则从 `inspiration.css` 移到 `atmosphere.css`，选择器是 `:is(.content-page,.pricing-page,.paper-home)`；灵感页专属的画廊、筛选栏和详情规则仍在 `inspiration.css`。页脚的绿色行动区只在灵感页隐藏，其他页保留。
- 面板内 `--site-muted` 为 `#4d525a`，所以测试里的灰字期望值从 `rgb(98, 102, 95)` 改为 `rgb(77, 82, 90)`；价格页根节点的背景期望值改为面板的 `rgba(255, 255, 255, 0.62)`。
- 共享按钮的阴影选择器权重是 3 个类（来自 `:is()` 里的 `.pricing-card.is-accent .pricing-button`），所以 `atmosphere.css` 里把 `.content-button` 的阴影清掉时用了 `:is(...):is(...)` 叠加权重；否则灵感页会多出第三种阴影，超出预算。
- 价格页自己的纸色横幅改为透明，卡片改成面板白，切换器改为胶囊。
- 未验证：窄屏下各页的版式只看了 390px 的几张截图，没有逐页逐宽度检查；Safari 和 Firefox 没测。

### 12.2 内页标题与页脚行动区（第三阶段）

- 内容页（`.content-page`）的页首统一为灵感页的比例：h1 为 `clamp(34px,5vw,68px)`、字重 400，上方留 64px（手机 32px）；说明文字仍是 16px，没有新增字号。
- 页脚行动区在所有页面由绿色实底改为半透明白加发丝线，标题 46px、字重 400（手机 34px）；灵感页仍然隐藏它。
- 文档页「从这里开始」卡片改为淡绿半透明底和发丝线边框。
- 仍未重做：各页内部的分栏和列表节奏（技能详情、赞助规则表、价格卡片内部）只继承了新页首，没有单独设计。

### 12.3 手机页头与标题断行（第四阶段）

- 手机（≤650px）页头会折成两行（品牌行和链接行），之前面板规则把 `.site-nav` 固定为 76px，发丝线正好从链接文字中间穿过。现在手机宽度下高度为 `auto`。
- 面板内所有 h1、h2 使用 `text-wrap: balance`，避免价格页标题末尾单字成行。
- 已用 390px 截图检查价格、赞助、投稿、案例、关于、更新记录页，没有横向溢出；其余页和 320px 没有逐页看。

### 12.4 灵感页的筛选栏、卡片和加载（试用反馈后）

- 筛选栏仍是 sticky（测试约定），但背景只剩 18% 的白色薄雾，不再用模糊白条把面板切成两半。
- 卡片里只有图片区垫浅灰底，署名区回到白卡片上；收藏和打开按钮移到卡片右下角、和署名同一行，不再盖在缩略图上。手机上这两个按钮仍是 44px。
- 手机首屏的页首间距收紧，介绍文字用 `text-wrap: pretty`；第一张卡片的顶部从屏幕 680px 处上移到约 647px（844px 高的屏幕上仍然只露出一小截，这是目前能做到的程度）。
- 加载方式：去掉了「列表下方的哨兵元素进入视口就加载」。横向条很矮，哨兵始终在视口里，会让 99 张卡片在页面打开时全部挂载（实测首页打开后 99 张，现在是 30 张）。现在条滚到离右端不足 1.5 个屏宽时加载下一批 30 张，「加载更多」按钮保留作后备。这也消除了 `inspiration-browsing` 里「时间流」用例约 15% 的偶发失败：那个用例在卡片数量中途读数时与自动加载抢跑。
- 未验证：真机手指滑动、Safari、Firefox；首页打开时视频请求的失败数量没有再测。
