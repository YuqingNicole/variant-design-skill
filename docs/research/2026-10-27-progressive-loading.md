# 按阶段加载改造前后对比 — 2026-10-27

基准见 `2026-10-27-eval-baseline.md`。这次用同一套 `evals/run.mjs`、同样的 3 个示例项目和指令，测试改造后的技能。

## 改了什么

- 总入口 `SKILL.md`：1,167 → 621 词。只保留分流表和各流程共用的规则，每条规则用一句话指向对应文件。
- 生成流程 `skills/variant-generate/SKILL.md`：3,932 → 1,362 词。开头放一张加载表，写明哪一步读哪个文件。变体动作移到 `actions.md`，局部改动移到 `zones.md`，都在用户提出时才读。
- `skills/shared/code-output.md`：3,875 → 约 1,900 词。只保留写代码时要用的内容。
  - Vue / Astro / Svelte 模板移到 `frameworks.md`；
  - 导出、接入、上线加固和剪贴板移到 `export.md`；
  - 去掉"写代码前总要读 micro-interactions 和 interactive-patterns"这条指令，改成"要做某个模式时只读那一节"。
- `preview-and-history.md` 拆成 `workflow/preview.md`（804 词）和 `workflow/history.md`（983 词），导出与接入部分并入 `export.md`。指向 `artifact-verification.md` 的链接移到导出阶段。
- 质量扫描跳过生成的预览包（`_static/`、`_preview/`），整个 `variant-output/` 可以直接用严格模式扫描。改之前这些预览包里打包进来的代码会产生警告，导致严格模式失败；加了回归测试。

## 结果

| 运行 | 检查全部通过 | 读取技能文字（前 → 后） | 用量（前 → 后） | 耗时（前 → 后） |
|---|---|---|---|---|
| pulse · Claude | ✓ → ✓ | 14,746 → 7,788 词 | $1.82 → $1.89 | 617 → 685 s |
| harbor · Claude | ✓ → ✓ | 15,076 → 8,118 词 | $2.46 → $1.93 | 1026 → 603 s |
| bakery · Claude | ✓ → ✓ | 14,919 → 8,895 词 | $2.00 → $1.98 | 589 → 739 s |
| pulse · Codex | ✓ → ✓ | 23,539 → 8,118 词 | 76.9 万 → 59.8 万 token | 309 → 307 s |
| harbor · Codex | ✓ → ✓ | 21,054 → 7,699 词 | 116.5 万 → 50.3 万 token | 513 → 389 s |
| bakery · Codex | ✓ → ✓ | 21,300 → 8,895 词 | 58.2 万 → 52.9 万 token | 324 → 280 s |

- 读取的技能文字：Claude 减少 40%–48%，Codex 减少 58%–67%。
- 两轮 12 次运行的检查全部通过，包括 pulse 的品牌锁定。
- 第二轮读取的文件和加载表一致：生成流程、项目检查、写代码、上下文、预览、质量、一份行业参考，以及权限页和面包店订单触发的产品完整性两份文件。变体动作、局部改动、历史、导出、验证报告和交互模式库都没有被读。
- 费用和耗时：每个组合只跑了一次，差异在正常波动范围内，不能据此说更快或更省。Codex 的 token 数都下降了，但其中包含缓存命中的输入。

## 过程中的发现

| # | 发现 | 处理 |
|---|---|---|
| 1 | 第一版统计漏算了"先 `cd` 进技能目录、再用相对路径读文件"的情况。bakery · Claude 被算成 3 个文件、2,732 词，实际是 10 个文件、8,895 词 | 统计改为同时识别相对路径，并排除 agent 自己写入的文件内容；加了测试。两轮数字都已重算，基准数字没有变化 |
| 2 | harbor · Codex 只读了 6 个文件，没读预览和质量规范，但仍生成了静态预览并运行了质量扫描，检查全部通过 | 记录下来。只读了总入口里的一句话就执行了对应命令，说明这几步在入口文件里写得足够清楚 |

## 局限

- 每个组合只跑一次。
- 只测了首次生成。变体动作、撤回和接入改成按需读取后，还没有实测；改动后的路径由 `skill-links.test.mjs` 检查，助手脚本的行为由单元测试和浏览器测试覆盖。
- 不判断设计好坏。
