# 灵感库第三批新增（2026-11-11）

灵感库从 99 条增至 129 条：20 条 X 视频帖、10 个官方网站。分类：网站 32→46、交互 27→34、动效 21→27、品牌 7→10，产品界面不变（12）。

## 做法

1. **候选来源**：recent.design 的首页、Branding / Interface / Motion / Web 分类页和 Websites 页，读的是页面里公开的条目数据（标题、原帖链接、分类），共 103 个候选，不抓取其余内容。
2. **筛除**：已收录的帖子 ID、已收录的作者（一人一帖）、已收录的站点域名；Illustration、Posters 类不选；不带视频的帖子不选。
3. **X 帖子**：用 `website/scripts/x-media.mjs` 读 X 嵌入组件使用的公开接口，得到正文、日期、视频地址、封面和头像；条目带 `via` 指回 recent.design 页面。
4. **网站**：用 `website/scripts/link-preview.mjs` 的解析读各站自己的分享预览图；`vercel.json` 的图片域名白名单同步增加。
5. **笔记**：中英文各写一句“看什么”和“用在哪”。
