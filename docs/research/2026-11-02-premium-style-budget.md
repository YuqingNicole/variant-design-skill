# 2026-11-02 "高级"的拆解与首页数量预算

## 起因

维护者希望"整体项目设计高级些"，并问"高级"能不能从 prompt 和 skill 两层拆开。

检索技能文本时发现：

- `premium` 被当成一种风格。方向表有 "Dark / Premium" 一行，色板里有 "Premium Black"。
- Agent 听到"做高级点"，最可能的做法是深色底加金色加衬线。
- 没有一个动作对应"更高级"。`quality-baseline.md` 只规定了不要做什么，没有规定最多用多少种字号、颜色、圆角。

## 拆解

"高级"主要来自克制、精确和自信，而不是某种视觉风格。可以检查的部分：

- 克制：字号、强调色、圆角、阴影的种类少。
- 精确：间距和字号来自 tokens。
- 字体细节：字号之间有明确的阶差，行宽合适，数据用等宽数字。
- 素材：真实截图，处理方式统一。
- 文案：具体，不夸张。
- 动效：少，只用来表达状态。

其中"种类少"可以直接计数，所以新增了 `scripts/style-budget.mjs`。

## 技能层改动

- `references/workflow/adjective-translation.md`：
  - 把"高级、简洁、科技感、年轻、温暖"等形容词翻译成可检查的属性；
  - A/B/C 用三种"高级"的读法（安静、编辑、精密），代替三种风格；
  - 给出默认预算。
- `skills/variant-generate/ROUTE.md`：
  - 加载表在 brief 含这类形容词时读上面的文件；
  - 方向表 "Dark / Premium" 改名为 "Dark / Atmospheric"，并注明"高级"不是一种风格。
- `skills/variant-generate/actions.md`：新增 `Refine premium`。顺序是：先量 → 收敛 → 轻度精简 → 打磨细节 → 改文案 → 再量。
- `scripts/style-budget.mjs`：
  - `probe` 在调用方自己的浏览器里运行，统计可见元素的字体、字号、字重、文字颜色、圆角和阴影；
  - `check` 按预算打分，可以加 `--before` 做前后对比；
  - 没有依赖；
  - 单元测试在 `scripts/style-budget.test.mjs`，真实浏览器测试在 `tests/loop.spec.mjs`。

## 首页实测

- 环境：本地构建（`website/server.mjs`），Chrome，1440×900，先滚到底让懒加载内容出现。
- 之前：同一分支改动前的构建。
- 之后：本分支的构建。

| 项 | 预算 | 之前 | 之后 |
|---|---|---|---|
| 字体 | 2 | 3 | 2 |
| 字号 | 7 | 15 | 7 |
| 字重 | 3 | 2 | 2 |
| 文字颜色 | 5 | 11 | 5 |
| 圆角 | 3 | 6 | 3 |
| 阴影 | 2 | 1 | 1 |

之后的取值：

- 字号：13 / 14 / 16 / 23（字标）/ 36.8（标题里的代码）/ 46 / 66px。
- 文字颜色：墨色、`--site-muted`、正文深灰 `#41463d`、品牌绿、主按钮白字。
- 圆角：6px、12px、胶囊。

### 主要改动

- **合并相近字号。**
  - 12、13px 合为 13px，包括页脚。
  - 14、15px 合为 14px，包括按钮、导航和语言切换。
  - 16、17px 合为 16px。
  - 区块标题 38、40、44、46、48px 统一为 `clamp(30px, 3.4vw, 46px)`。
  - 案例卡片标题从 19px 改为 16px，字重 500。
- **合并一次性颜色。**
  - `#456133`、`#5d6e4f` 改为品牌绿。
  - `#3d4339` 改为正文深灰。
  - `#33402c` 改为墨色。
  - 案例切换按钮里的字母不再用等宽字体和两种浅绿：未选中时用 `--site-muted`，选中时继承白色并降低不透明度。
- **统一圆角。** 3、4、5px 改为 6px。

## 没有验证的

- 计数下降只说明更克制，不证明更好看。
- 截图对比只看了 1440 宽度的中文首页，以及 390 宽度没有横向滚动。
- 英文版、320 宽度和其他页面没有逐一截图。
- `library.css` 的改动也会影响案例详情页和 `/library` 系列页面，这些页面只跑了 landing 测试，没有单独计数。
- 没有跑真实 Agent 的 eval 来检验 `Refine premium` 动作和形容词翻译在 Claude Code 或 Codex 里的实际效果。这需要新增一个"把这个页面做得更高级"的 fixture。
