## Design and boundaries

Failed runtime checks optionally retain actual structured diagnostics (bounded unique id/message, relative file and positive position). Comparison uses explicit diagnostic/check/tool/environment identities while retaining actual log evidence; log paths or a changed check summary alone do not turn an identical prior diagnostic into a new one. Legacy reports without diagnostics keep strict whole-observation comparison. Old/new failures both remain failed. These are observed diagnostic identities, never inferred root causes. The existing bounded declarative executor is exported for trusted adapters; it does not itself establish source/baseline preservation.

Original HTML fixture preserves the Progress Review brand, real classic-script RAF and independent activity behavior. It adds protected original Node syntax/health commands and an intentionally existing health diagnostic. The real Agent must retain it, run actual commands, create version-bound before/after reports, apply multi-file index/delivered-resource staging, seal a failed candidate receipt before rollback, then restore the original entry and remove new resources. The receipt is historical after rollback; no accepted/production-ready claim is permitted.

The host checks installed helpers, direct baseline/post-undo/delivery archives, exact source metadata and all A/B/C bytes, actual targets/backup/staging, separate command logs/diagnostics and historical receipt references. It does not execute Agent-authored check adapters. In an independent materialized archive it reruns real project commands and browser observations against A/B/C, comparison and actual original/integrated entry, retaining source response bytes, errors and 390/1440 preview coverage. A separate real integration of a staged syntax regression must keep the original health diagnostic observed-before and the syntax diagnostic new-or-changed, with failed verification. Controlled prepare/rollback conflict probes preserve edits. Restore removes created resource files and restores originals; probes do not mutate the Agent project.
