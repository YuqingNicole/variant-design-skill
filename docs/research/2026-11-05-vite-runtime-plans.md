## Scope and method

A real Agent must generate A/B/C and author B baseline, edit and undo plans from actual original source/brand. The fixture has original ReviewProvider/useReview, local JSON, @ alias, a Vite define, Georgia brand, independent per-workspace progress/activity, owner/viewer permission and actual RAF reduced-motion handling. Isolated preview HTML/TSX belongs in .variant-work/preview; registered candidate sources remain in variant-output. Task coverage and expectations are authored by the Agent, never inferred by host keyword rules.

Host Vite mode verifies original files/config against the controlled fixture, direct phase archives and current source/plan inputs. It reuses the existing independent Vite worker on an owned ephemeral loopback port and real TypeScript checks, requiring listed generated components and both original/B build outputs. Each fresh server loads actual B with the original define and viewport; actual response hashes, HTTP/page/request failures and tool versions remain visible. The host does not import Agent verification callbacks, execute JSON commands or rewrite the Agent's source/selection.

Vite transforms responses; file URL byte equality is not used. Each phase materializes its direct archive outside the Agent project, copies dependencies, and alters original data, original provider title and original brand marker there. Actual B must follow the provider/data/CSS nonce, preserve the real animation and independent workspace roles/counts. A copied provider still importing original data cannot pass. Source before/after is checked; only owned worker handles stop. Additional Vite project/probe gates require actual Vite observations and cannot pass from file-only/missing host records. Existing HTML mode remains supported. Separate native-delivery and runtime-plan fixture flags are explicitly rejected together rather than creating duplicate phase archives.

Design inputs and limits: RFC-015 Vite extension; official Vite JavaScript API and Playwright Network docs. Actual compatibility is pinned Vite 7.3.6/TypeScript 5.9.2/Playwright 1.56.1; copied local dependency tests use those installed versions. Local trusted observer/source hashes are not publisher authentication, full environment freshness, universal framework support, human acceptance or complete delivery coverage.
