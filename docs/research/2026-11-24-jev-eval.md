# Jev（OneJev-0.8B）能不能帮素材库打属性

2026-11-24。本地跑 `mradermacher/OneJev-0.8B-GGUF:Q8_0`（Apache-2.0，llama.cpp + 官方 `qev` 服务，无需 key），M2 8 GB 上每张图约 15–22 秒。

## 测法

以已经由代理核对过的属性为标准答案，给模型看 40 个网站首屏截图和 23 个视频封面，每个问题让它回答「是」的概率（`/v1/systemone`，`noul` 题型）。

| 问题 | AUC | 说明 |
|---|---|---|
| 网站：整体深色 | 0.98 | 阈值 0.95：准确率 0.95，精确率 0.92，召回 0.92 |
| 视频：整体深色 | 0.98 | 阈值 0.8：准确率 0.91 |
| 有用户评价区 | 0.86 | |
| 有产品界面截图 | 0.82 | |
| 有客户 logo 墙 | 0.74 | |
| 移动端界面 | 1.0 | 只有 3 个正例，不可信 |

## 结论

- 只让它判断「深色」这一项，概率 ≥ 0.95 才写进初稿；其余属性留空，媒介按条目类型推出。
- 它不参与收不收录的决定（那仍由读帧的大模型筛选）。
- 它写的都是初稿（`status: draft`，`draftedBy: jev`，`jev: {dark: p}`），公开页面只计已核对的记录。核对页 `npm run review:facets` 的「Jev 判断」分组和统计报告会列出它判断过的条目和概率；核对后仍保留这两个字段，方便以后回看它猜得准不准。

## 运行方式

`website/scripts/jev-facets.mjs` 读 `JEV_URL`；没有就什么都不做。每日任务在本机启动 `qev serve --port 8799`，收录完新条目后起草属性，任务结束即关掉服务，不常驻。
