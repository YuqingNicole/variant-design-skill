# PRD-006 · 发行包分发与安装验证

跟踪 Issue：https://github.com/YuqingNicole/variant-design-skill/issues/24

- 优先级：发布必需；状态：待实现。
- 依赖：PRD-000；可先用测试权益开发，正式领取接 PRD-005。

## 问题与解决方案

已有 RC 打包与解压 smoke test，尚未证明用户能在实际 Codex 环境安装并发现插件。交付不可变发行包和经过验证的安装路径，最后通过宿主识别及项目内辅助工具运行确认成功。

## 用户故事

1. 作为购买者，我希望下载的是明确版本的完整包，而非孤立 SKILL.md。
2. 作为购买者，我希望安装前知道宿主、系统、Node 和项目要求。
3. 作为购买者，我希望校验下载完整性并识别版本。
4. 作为购买者，我希望完成安装后能确认技能可用。
5. 作为购买者，我希望缺少依赖时获得具体诊断。
6. 作为已有免费版用户，我希望版本共存或替换规则清楚，不出现重复调用。
7. 作为购买者，我希望卸载不删除项目产物和历史。

## 实现决策

- 每个发行包有稳定版本、校验清单、构建来源、兼容矩阵、变更说明及许可清单，不在同一版本名下静默替换内容。
- 校验和证明传输完整性，不单独证明发布者身份；包和校验信息须来自可信领取/发布渠道。
- 复用现有完整目录打包能力，排除网站、开发依赖、本地项目数据与凭据。
- 安装方式以实际支持并验证过的 Codex 路径为准。不得伪造一键安装链接，也不得把解压成功当成安装成功。若付费私有分发不可行，先调整交付方式再开放销售。
- 安装检查分为环境检查、宿主发现、项目内调用三步，报告已检查与未知项。
- 测试从安装位置调用预览与历史 helper，保证没有引用开发者 checkout。
- 免费版与 Pro 的命名、升级/替换策略必须在干净环境测试后写入说明，不默认修改全局配置或已缓存插件。

## 验收清单

- [ ] D1：干净环境从领取包完成实际安装，宿主发现正确技能与版本。
- [ ] D2：从仓库外运行安装包工具，三版预览和 scoped apply/undo 工作正常。
- [ ] D3：损坏包、错误平台/依赖和旧版本均有具体恢复指引。
- [ ] D4：记录免费版已安装时的行为，避免重复技能或静默覆盖。
- [ ] D5：包内不存在凭据、用户代码或本地状态；许可及资源来源可核对。
- [ ] D6：卸载与重新安装保留用户项目、历史和已导出成果。
- [ ] D7：发布兼容矩阵只列实测环境；市场上架和私有分发分别说明。

## 测试决策

保留当前打包解压回归，再增加实际宿主安装和发现检查；记录系统、宿主版本、包摘要、工具路径与结果。不能用模拟的安装成功页面替代。

## 不在范围内

自行发明宿主插件协议、自动安装未知平台、未经验证承诺市场付费功能、公开提交审核。

## 完成证据

真实安装记录、发行清单、安装路径验证、免费版兼容记录、卸载恢复结果。
